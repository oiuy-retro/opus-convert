# Known issues

Recorded 2026-10-21. These are still the default Windows look. They need the same Windows 2.03 chrome as the rest of the window (flat black frames, 50% checkerboard dither).

## Scrollbars

Page and list scrollbars still look like ordinary Windows scrollbars. They should use a dithered track, a thick black frame, and square arrow boxes.

## Dropdown lists

The closed combo face (Profile, insert-mode menus) already has a thick black frame. The open popup list under those menus still looks like a default Windows combo. The dropped list needs the same owner-drawn chrome.
